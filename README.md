# Sobre mim

Olá! Sou estudante de Cibersegurança, com foco em Segurança Ofensiva e Defensiva, e tenho como principal objetivo profissional me tornar Pentester e atuar na área de segurança da informação. Também estudo desenvolvimento de software, buscando aprofundar meus conhecimentos em programação, sistemas operacionais, redes e análise de vulnerabilidades.

Atualmente, estudo e pratico programação com Bash Scripting, PowerShell, C, Assembly, Python e Go (Golang). Também estou estudando HTML e CSS e tenho interesse em expandir meus conhecimentos para JavaScript, C++, COBOL, Pascal é C#

Na área de cibersegurança, mantenho uma rotina de estudos que envolve diferentes cursos e trilhas de aprendizagem, incluindo:

Cursos e materiais em andamento:

- DESEC Pentest Profissional 2023 — atualmente no módulo de criação de exploits em Assembly.
- Solyd Pentest Profissional.
- DESEC — Técnicas de Evasão de Defesas.
- Cybrary — Become a SOC Analyst, níveis 1, 2 e 3.

Formações e certificações que estou estudando para obter:

- Solyd Pentest 3.0.
- PortSwigger Web Security Academy.
- CCNA — Cisco.
- Red Team Leaders:
  - Técnicas Práticas de Evasão de AV/EDR.
  - Introdução à Análise de Malware v1.
  - Segurança Operacional e Anonimato para Equipes Vermelhas.

E tenho enteresse em fazer Microsoft SC-900

Para consolidar o conhecimento adquirido, utilizo o Obsidian para organizar minhas anotações, documentar conceitos técnicos e registrar meus aprendizados. Acredito que escrever, revisar e explicar os conteúdos com minhas próprias palavras são práticas importantes para desenvolver uma compreensão mais profunda dos assuntos estudados.
